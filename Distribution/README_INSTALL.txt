THE AMAZING NADA by BoxBap
INSTALLATION & SETUP GUIDE
==================================================

OPTION 1: AUTOMATIC INSTALLER (RECOMMENDED)
--------------------------------------------------
Double-click "The_Amazing_Nada_Installer_v1.0.exe" to automatically install the VST3 plugin, the standalone application, and an optional desktop shortcut.

NOTE ON WINDOWS SMARTSCREEN:
Because Box Bap is an independent boutique developer, Windows SmartScreen may display an "Unrecognized App" or "Windows protected your PC" prompt on first run. Simply click:
  "More info" -> "Run anyway"

OPTION 2: MANUAL INSTALLATION
--------------------------------------------------
If you prefer not to use an installer, open the "Manual_Installation" folder:
- VST3: Copy "The Amazing Nada.vst3" to:
  C:\Program Files\Common Files\VST3\
- STANDALONE: Run "The Amazing Nada.exe" directly from the Standalone folder.
